你好！

我是 吴小黑（WuXiaoHei），在武汉大学从事 有机太阳能电池（OSC）相关研究。主要关注器件在应力条件下的退化路径： 反向偏压区的非欧姆拐点、载流子迁移率与复合的温度依赖， 以及用短期加速老化数据外推长期寿命时模型的可外推性。

研究方法上，我倾向于「物理模型 + 数据驱动」的混合路线 —— 先用物理约束搭骨架， 再让机器学习去学残差，而不是把黑箱直接丢给数据。实验这边，我主要做阻抗谱（EIS）、 偏压扫描与高通量老化测试。

工程侧，我给实验室搭了整套工具链：从 HP/Agilent 4284A 的阻抗谱自动化采集， 到用 KiCad 重画的源表 μSMU-neo，再到高通量测试治具的 CAD 设计。

科研之外我拍照，下面「摄影」一栏就是放我作品的地方。

研究

以下方向对应我公开在 GitHub 上的工作。

  • 有机太阳能电池稳定性预测

    用短期（200 h）加速老化数据预测长期（500–2000 h）的 PCE 保持率。 核心是「物理模型外推 + 机器学习学残差」，并搭建 Transformer 时序分支做对照。

    多光强（1x / 1.5x）短期曲线 · 5 折交叉验证 · 五个目标时刻

    Code

  • 反向偏压下的电流拐点机理

    面向 PM6:Y6 体系，研究反向偏压区「拐点」（reverse-bias knee）的来源。 采用无外部分流电阻的本征模型，在 100–300 K 内做温度扫描与数值审计， 并保留完整的实验约束与可复现审计链。

    物理模型 · 专家评审包 · 哈希清单校验

    Code

  • EIS 阻抗谱自动化测量系统

    通过 VISA/GPIB 控制 HP/Agilent 4284A，做频率扫描与复阻抗采集， 实时绘制 Nyquist 与 Bode 曲线，支持开短路校准、CSV 导出与等效电路拟合。

    命令行 · 桌面 GUI · 无硬件仿真模式

    Code

  • μSMU-neo 开源源表改版

    基于开源 μSMU 的改版：保持 ±5 V / ±40 mA 量程不变，修正原设计评审中的安全与采样问题， 更新 IC 型号至国内现货可采购，并在 STM32G431 上重写固件。

    KiCad 10 · 国产供应链 · 许可合规保留署名

    Code

  • 高通量 OSC 测试治具

    面向高通量老化测试的机械治具与夹具设计，包含 25 mm 片子及其盖板的三维 CAD 模型， 用于支撑多器件并行测试的装夹与定位。

    SolidWorks 2025 导出 STEP AP203

    Code
